# AgriLoop AI – Frontend 🌱

## Project Overview
AgriLoop AI is an agriculture-focused web application frontend designed to display agricultural products and provide a user-friendly interface for farmers and customers.

## Features
- Display agricultural products
- Product images and details
- Clean and responsive user interface
- React component-based design
- Integration-ready with the backend API

## Technologies Used
- React.js
- Vite
- JavaScript
- HTML5
- CSS3
- npm

## Requirements
- Node.js
- npm
- Visual Studio Code

## Installation and Execution

1. Open the frontend folder in VS Code.
2. Open the terminal.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in the terminal, usually `http://localhost:5173`.

## Backend Integration
The frontend is designed to work with the AgriLoop AI backend built using Java Spring Boot and MySQL.
